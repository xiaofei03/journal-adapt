# journal-adapt

This skill adapts one frozen submission mother to one locked journal destination. It preserves Zotero fields and empirical evidence, uses cached journal profiles, maintains one Word work pair, and stores only canonical manuscripts, a cumulative revision ledger, consolidated audits, figures, and submission materials.

Journal discovery belongs to `journal-selection-pro`. Temporary Word files, probes, and renders belong to `_work/<run_id>/`.
